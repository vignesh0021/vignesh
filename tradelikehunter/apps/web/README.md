# @tlh/web — React + Vite + Tailwind SPA

The product UI. Feature-first (`src/features/*`), atomic design system from `@tlh/ui`,
server state via TanStack Query, realtime + UI state via Zustand, forms via RHF + Zod
(`@tlh/contracts`), charts via Recharts + a TradingView-lite candle chart, motion via
Framer Motion. Mobile-first responsive with a bottom tab bar; installable PWA.

Implemented starting **M0** (AppShell, theme, auth) and filled in per module across M1–M8.
See [`../../docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md).
